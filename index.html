Put your directories on the cutting board.

doma is a workbench for sets of project directories. Label them once, then check or run a whole label at a time.

Read the docs $ brew install hahwul/doma/doma

One static binary. No runtime dependencies. MIT licensed.

Label once. Then work on the whole set.

  1. Label

    Tag a directory with whatever makes sense: a language, a client, this week's spike. Tags can expire on their own.

    doma add . -t crystal -t work

  2. Look

    See every repo under a label at once: branch, ahead and behind, uncommitted files, stashes, last commit.

    doma status work

  3. Run

    Run a command in each one. Whatever fails is listed again at the end.

    doma run work --parallel -- git fetch

  4. Retry

    Sets like @failed and @dirty are worked out when you ask, so you only redo what needs it.

    doma run @failed -- make test

Why a cutting board

I kept losing track of where things lived — twelve Crystal repos in one folder, seven shell experiments in another, the security write-ups elsewhere. cd's history wasn't enough; fuzzy finders forgot what mattered the moment I cleared the terminal. So I wrote a cutting board: pin the directories I care about, label them with whatever tags make sense (crystal, work/proj-a, reading-this-week), and let the tool do the recall.

도마

/do·ma/, noun, Korean

The cutting board: the workbench where ingredients get gathered, grouped, and chopped before going into the pan. The metaphor stuck.
